# `audio-forge` skill 设计

日期：2026-10-13  
状态：用户已确认执行

## 目标

创建一个可复用的 Codex skill，用本地 Python 生成短音乐和音效 WAV。首版不依赖联网服务、外部音频模型或 DAW。

## 范围

- 支持音乐、循环段和事件音效的 brief 驱动生成。
- 生成可编辑 Python 源脚本和 PCM WAV。
- 检查输出的时长、采样率、声道、位深、峰值和削波。
- 提供常见音效和短音乐的起始预设。
- 不包含 MIDI、DAW 工程、外部模型调用、采样包下载或专业母带处理。

## 工作流

1. 解析 brief 并补齐关键参数。
2. 生成 `brief.md`、时间轴和参数表。
3. 写入可编辑 Python 合成脚本。
4. 运行脚本渲染 WAV。
5. 用 WAV 检查脚本验证实际输出。
6. 输出 WAV、源脚本和 README，并报告绝对路径与检查结果。

## 验证

- skill 通过 `quick_validate.py`。
- 合成脚本只使用 Python 标准库并能生成有效 WAV。
- 检查脚本能读取示例 WAV，并可在 `--fail-on-clip` 下报告削波。
