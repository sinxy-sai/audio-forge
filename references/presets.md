# Audio Forge 起始预设

这些数值是起点，不是硬性风格规则。根据用途、设备和用户试听反馈调整。

## 音乐

| 类型 | 时长 | 速度 | 常用材料 | 结构建议 |
| --- | ---: | ---: | --- | --- |
| 科幻 UI 背景 | 8–16 秒 | 80–120 BPM | 低频脉冲、悬挂和弦、上行提示音 | 两小节动机，四到八小节循环 |
| 轻量游戏氛围 | 20–60 秒 | 70–110 BPM | 三角波铺底、稀疏打击、短延迟 | 低密度开头，中段加入一个变化 |
| 紧张提示循环 | 4–12 秒 | 100–140 BPM | 低音 ostinato、重复音型、噪声扫频 | 尾部与开头保持同一拍点 |

## 音效

| 事件 | 时长 | 起始频率 | 结构 |
| --- | ---: | ---: | --- |
| UI 点击 | 50–160 ms | 800–2200 Hz | 短瞬态 + 快速衰减 |
| 确认 | 180–500 ms | 400–1000 Hz | 两个上行音符，第二个略长 |
| 警告 | 300–900 ms | 250–900 Hz | 两个交替音或重复脉冲 |
| 冲击 | 180–700 ms | 70–180 Hz | 快速降频正弦/三角波 + 噪声爆发 |
| 上升提示 | 300–1000 ms | 250–1400 Hz | 频率上滑 + 轻微高频纹理 |
| Whoosh | 250–900 ms | 150–2500 Hz | 噪声包络 + 频率或声像移动 |

## 混音起点

- 预留约 1 dBFS 峰值余量；生成后用 `python -m audioforge inspect` 检查实际峰值。
- 叠加层先少后多，每增加一层都重新检查峰值和尾音。
- UI 音效通常需要短尾巴；环境或氛围音乐可以使用更长的衰减。
